# 命名规范

## Skill 命名规则

1. 使用小写字母
2. 使用连字符 `-` 分隔单词
3. 名称要简短
4. 避免模糊名称
5. 优先使用工作流命名

## 好的命名

| 名称 | 说明 |
|------|------|
| pr-review | 代码审查 |
| repo-analysis | 仓库分析 |
| paper-reading | 论文阅读 |
| test-writer | 测试编写 |
| clean-dead-code | 死代码清理 |

## 不好的命名

| 名称 | 问题 |
|------|------|
| PRReview | 不是 kebab-case |
| repo_analysis | 使用了下划线 |
| Paper Reading | 包含空格 |
| general-helper | 过于模糊 |
| my-skill | 没有描述功能 |
